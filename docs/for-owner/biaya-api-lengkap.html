Urutan Daftar yang Disarankan

Minggu 1: Domain & Email

  1. Beli domain di Niagahoster/Cloudflare (~Rp 150-270rb/tahun)
  2. Verify domain di Resend (gratis, edit DNS)
  3. Setup domain di Vercel (gratis, edit DNS)
  4. Update env var RESEND_FROM_EMAIL ke noreply@namatoko.com

Hasil: Website punya nama sendiri + email pro dari domain sendiri.

Minggu 2: Payment Gateway

  1. Daftar Midtrans Sandbox (gratis, langsung aktif)
  2. Test integrasi di sandbox
  3. Ajukan Production (KYC: KTP + rekening)
  4. Tunggu approval 3-7 hari kerja
  5. Switch ke Production keys

Hasil: Pembeli bisa bayar QRIS/VA/e-wallet di website.

Minggu 3: Ongkir Otomatis

  1. Daftar RajaOngkir Starter (gratis) untuk test
  2. Integrasi ke checkout
  3. Upgrade ke Basic Rp 50rb/bulan saat siap go-live

Hasil: Pembeli lihat ongkir & pilih kurir saat checkout.

Minggu 4+: Polish

  • WhatsApp notif (Fonnte ~Rp 50rb/bulan)
  • Halaman tracking pesanan
  • Optimasi foto produk

Yang Bisa Hemat

  • Pakai RajaOngkir Starter dulu sambil test. Upgrade Basic saat banyak pembeli komplain JNE/J&T tidak ada.
  • Tunda Vercel Pro sampai trafik benar-benar tinggi. Hobby plan handle ribuan visitor/bulan.
  • Tunda Supabase Pro sampai database/storage hampir penuh.
  • Domain .com lebih murah dari .id (Rp 150rb vs Rp 270rb/tahun).
  • Cloudflare adalah provider domain termurah (tapi tidak ada support Indonesia).

Yang Sebaiknya JANGAN Hemat

Jangan pakai gateway pembayaran tidak resmi. Ada penyedia "gateway" murah yang sebenarnya bukan licensed Bank Indonesia. Risiko: uang ditahan, akun ditutup tiba-tiba, atau ditolak bank. Tetap pakai Midtrans/Xendit/Doku yang official.
Jangan skip KYC Midtrans. Akun sandbox tidak bisa terima uang sungguhan. Production butuh KTP + rekening + verifikasi.
Jangan pakai email gratis (gmail.com) untuk notifikasi toko. Pembeli akan curiga. Email dari domain sendiri (noreply@namatoko.com) terlihat profesional dan dipercaya.
